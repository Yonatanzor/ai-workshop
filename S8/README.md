# Session 8 — From Workshop to Project (Capstone)

**Type:** 90-minute session + Session 9 showcase  
**Audience:** First-semester MD-PhD students  
**Data tier:** Determined by each group's chosen project (check before starting)

---

## What this session is

The last working session before the showcase. Students look back across seven sessions, choose one AI workflow to adopt and develop into a short project, and take the first real step on it — in the room, with instructors present.

## Session structure

| Time | Activity |
|---|---|
| 0–10 min | **Look back** — seven sessions, seven methods, and the habits they share |
| 10–80 min | **Start** — in groups: scope the project, check the data tier, plan the verification, take the first step |
| 80–90 min | **Share** — one minute per group: our task is…, we chose this track because…, we will know it works when…, what worries us most is… |

## The seven methods reviewed

| Session | Method |
|---|---|
| S1 | Families of AI, four data tiers |
| S2 | Six realistic bugs in a proteomics analysis |
| S3 | One paper, many audiences: NotebookLM and Gamma |
| S4 | Write the rules once: guardrailed assistants |
| S5 | Retrieval-augmented generation |
| S6 | Agents: tools, loop, supervisor |
| S7 | Vibe coding and rapid prototyping |

## Scoping a project — four questions to answer before starting

1. What is the task? (One sentence.)
2. What data tier does it involve? (Check before anything is sent to a tool.)
3. How will you verify that it works? (What would a wrong answer look like?)
4. What is the most likely failure mode?

## The Session 9 showcase

Each group gets **6 minutes:**

- The problem
- A live demo
- Their verification method
- Their one failure (from the failure log, or found during the project)

Then **2 minutes of questions:** each group is assigned one sharp question for another group.

**The deck** is made with Gamma or NotebookLM (Session 3 tools), with an AI disclosure on the last slide.

> A live demo that fails on stage is fine, if you can explain why. A slide that hides a failure is not.

## Notes for instructors

This session works best when instructors circulate actively during the 70-minute work block and help groups narrow scope — the most common problem is a project that is too broad to demonstrate anything in six minutes. Push groups toward a task with a verifiable output: a question the tool answers that can be checked against a ground truth, or a workflow that produces a concrete artefact they can show on screen.
