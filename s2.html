Learning Objectives

By the end of this session you will be able to:

  1. Apply the inspect → predict → check → fix loop to AI-generated data-analysis code
  2. Identify planted errors in statistical code that run without exceptions but give wrong answers
  3. Confirm a biological result using a second, independent method

Before the Session

  • CPTAC endometrial cancer proteomics dataset overview
  • What is microsatellite instability (MSI)?

The Activity

The question
What do MSI-H endometrial tumors lose — and gain — at the protein level compared with MSS tumors?
A colleague asked an AI to analyse a proteomics dataset. The code runs, produces figures, and gives wrong answers. Working in pairs, students apply a five-step review loop — intent, data flow, definitions, method, plausibility — to find six planted errors. The dataset is real: 104 endometrial tumors from the CPTAC study, and the question is clinically meaningful: what do MSI-H tumors lose at the protein level?

ℹ️ Instructor note
The student notebook contains subtle planted errors that run without exceptions but produce wrong answers. Do not hint which cells are affected — the discovery is the point.

Critical-Thinking Challenge

One of the results in the notebook would change if you used the correct statistical test. Find it, fix it, and explain why the original answer was wrong.
