Learning Objectives

By the end of this session you will be able to:

  1. Connect to a large language model through an OpenAI-compatible API
  2. Write a system prompt that restricts topic, tone, and output format
  3. Find at least two ways to make your own assistant break the rules you set

Before the Session

  • What is a system prompt?
  • How function calling works in the OpenAI API
⚙️ Before the session
Get a free Gemini API key at aistudio.google.com/apikey — no credit card needed. Never share or paste the key into a code cell.

The Activity

Students move from using AI tools to building one. Working through an API for the first time, each student writes a system prompt that defines a guardrailed assistant for their own work, tests it, and then tries to break it. The session teaches what a system prompt can and cannot control — and what happens when someone rewrites the rules mid-conversation.
Google ColabGemini API — free key at aistudio.google.com/apikey

Critical-Thinking Challenge

Break your guardrail three ways: rephrasing the question, claiming a special role, hiding the instruction in a longer text. Log which worked and design a fix for each.
