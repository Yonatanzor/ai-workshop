Learning Objectives

By the end of this session you will be able to:

  1. Implement a tool-use loop with function calling
  2. Explain how the agent decides which tool to call next
  3. Read an agent's step log and identify every action taken without verification

Before the Session

  • What is an AI agent?
  • How function calling enables tool use

The Activity

An agent is a model in a loop: goal → choose a tool → act → read the result → repeat → stop. Students build five tools (ClinicalTrials.gov, PubMed, age-check, e-mail), register them with an LLM, and run the loop on a real oncology case. Then they add a supervisor, approve or refuse each action, and ask: which steps should a hospital agent never take without a human in the loop?

ℹ️ Instructor note
Sending email is simulated — the agent writes to a file, it does not send. The patient case is from a published case report (CC BY-NC 4.0); everything sent to the model is public (Tier 1).

Critical-Thinking Challenge

Read the agent's step log and mark every action it took without checking the result. Then watch the prompt-injection demo: a hidden instruction on a web page changes what the agent does. What guardrail would prevent it?
