Learning Objectives

By the end of this session you will be able to:

  1. Build a functional web app from a one-paragraph natural-language description
  2. Identify content the tool invented without being asked
  3. Audit an app's privacy defaults and write an accurate AI disclosure

Before the Session

  • No specific pre-reading required.

The Activity

Base44Google AI Studio
ℹ️ Instructor note
Both tools default to Public visibility. Check privacy settings before entering any real data.

Critical-Thinking Challenge

Governance audit: Who can see your app right now? What did it invent? What is in the export file? Write a one-line AI disclosure that accurately describes what AI did and did not do.
